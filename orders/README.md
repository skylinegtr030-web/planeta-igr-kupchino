# Заявки

Каждая заявка с сайта сохраняется отдельным JSON-файлом в папке текущего месяца:

```
orders/2026-10/2026-10-15-<uuid>.json
```

Их читает и обновляет админ-панель `/admin` через функции Vercel:

- `POST /api/order` — приём новой заявки с сайта (валидация внутри функции).
- `GET  /api/orders` — список заявок для панели (нужен GitHub-токен).
- `PATCH /api/orders` — смена статуса заявки.

Статусы: `Новая`, `В работе`, `Подтверждена`, `Отклонена`.
