# Заявки

Каждая заявка с сайта сохраняется отдельным JSON-файлом в папке месяца:

```
orders/2026-10/2026-10-15-<uuid>.json
```

Как это работает:

- `POST /api/order` — приём новой заявки с сайта (валидация внутри функции).
- `POST /api/admin (action=login)` — вход в панель по логину и паролю
  (переменные окружения Vercel: `ADMIN_LOGIN`, `ADMIN_PASSWORD`).
- `GET/POST /api/admin` — чтение контента, списка заявок, смена статуса,
  загрузка фото. GitHub-токен (`GH_TOKEN`) живёт только на сервере,
  в браузер попадает лишь короткоживущая сессия.

Статусы: `Новая`, `В работе`, `Подтверждена`, `Отклонена`.
Смена пароля в переменных окружения Vercel мгновенно завершает все активные сессии.
